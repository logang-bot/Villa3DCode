Read all four files in the docs/ directory: project-overview.md, workflow.md, systems.md, and scene-setup.md.

Then give a structured session briefing in this exact format:

## Current Phase
One sentence on which milestone phase we are in and what percentage of it is done.

## What's Built
Bullet list of completed systems — one line each, no script details, just what exists and works.

## Where We Left Off
One or two sentences describing the exact stopping point from the last session.

## Next Task
The single next thing to work on, with a one-sentence description of what it involves.

## Watch Out For
Any gotchas, key decisions, or non-obvious constraints from the docs that are relevant to the next task.

Be concise. This is a startup briefing, not a full documentation summary.
